# AGENTS.md

This repository's instructions for coding agents live in ONE file:
**[CLAUDE.md](CLAUDE.md)**. Read it in full before working here. Everything in
it applies to any coding agent as written (build and test commands,
architecture, how the stack conventions land in this package). The stack
conventions themselves (naming and verbs, signatures, data arguments, frames
and normalization) live in VisualGeometryCore's `conventions/` folder; CLAUDE.md
says where to find it. Read them too.

Where CLAUDE.md names Claude in the commit rules, read it as any agent: never add
an AI co-author line or a "generated with" footer to a commit message.

This file used to be a renamed copy of CLAUDE.md. The copy drifted; a pointer
cannot.
